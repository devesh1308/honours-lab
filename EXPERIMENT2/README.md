# Experiment No. 2

## Title

System Prompt Engineering for Structured JSON Data Extraction using Large Language Models

---

## Objective

To understand how carefully designed system prompts can extract information from unstructured engineering fault logs into predefined JSON schemas suitable for software applications.

---

## Problem Statement

Develop a Python application that uses a Large Language Model (LLM) to transform unstructured engineering fault logs into structured JSON while enforcing strict schema constraints through prompt engineering.

---

- Visual Studio Code
