# Experiment No. 1

## Title

Study of the Effect of Temperature and Top-p Hyperparameters on Large Language Model (LLM) Responses.

---

## Objective

To understand how changing the **Temperature** and **Top-p** hyperparameters affects the quality, diversity, creativity, and consistency of responses generated by a Large Language Model.

---

## Problem Statement

Large Language Models provide several decoding parameters that influence text generation. This experiment studies the effect of varying Temperature and Top-p values while keeping the input prompt constant.

---

## Software Requirements

- Python 3.x
- VS Code
- OpenAI Python SDK
- Internet Connection

---

## Prompt Used

```
Write a three-sentence intro for a novel about an autonomous robot studying ocean ecosystems.
```
