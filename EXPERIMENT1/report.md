# Experiment No. 1

# Title

Study of Temperature, Top-p and Frequency Penalty Hyperparameters in Large Language Models.

---

# Aim

To study the effect of Temperature, Top-p, and Frequency Penalty hyperparameters on the responses generated by a Large Language Model (LLM).

---

# Theory

Large Language Models (LLMs) generate text by predicting the next most probable token based on the previously generated words. The quality, creativity, and diversity of the generated response can be controlled using different sampling hyperparameters.

## Temperature

Temperature controls the randomness of the generated output.

- Lower values (near 0) generate deterministic and predictable responses.
- Higher values produce more diverse and creative outputs.

## Top-p (Nucleus Sampling)

Top-p limits token selection to the smallest set of words whose cumulative probability exceeds the specified threshold.

- Lower values generate focused and conservative responses.
- Higher values allow greater diversity while maintaining coherence.

## Frequency Penalty

Frequency Penalty reduces the repetition of words or phrases.

- Lower values allow repeated words if necessary.
- Higher values encourage the model to introduce new vocabulary and reduce redundancy.

# Sample Prompt

```text
Write a three-sentence intro for a novel about an autonomous robot studying ocean ecosystems.
```

# Procedure

1. Install the required Python libraries.
2. Configure the Groq API key using the `.env` file.
3. Initialize the OpenAI-compatible Groq client.
4. Use the same prompt for every experiment.
5. Execute the program with different combinations of Temperature, Top-p, and Frequency Penalty.
6. Record the generated responses.
7. Capture screenshots of the code and outputs.
8. Compare the responses and analyze the effect of each hyperparameter.

---

# Experimental Results

| Run | Temperature | Top-p | Frequency Penalty | Observation |
|-----|------------:|------:|------------------:|-------------|
| Run 1 | 0.0 | 0.10 | 0.0 | Generated a highly deterministic and focused introduction with minimal creativity and predictable wording. |
| Run 2 | 1.2 | 0.95 | 0.0 | Produced a more creative and expressive introduction with richer vocabulary and descriptive storytelling. |
| Run 3 | 0.7 | 0.80 | 1.5 | Generated a balanced response with good coherence while reducing repetition through the frequency penalty. |

---

# Result Analysis

The experiment demonstrated that different hyperparameter values significantly influence the quality and style of the generated text.

- **Run 1** produced the most deterministic response because of the very low Temperature and Top-p values.
- **Run 2** generated the most creative output due to the high Temperature and Top-p values, resulting in richer descriptions and more imaginative storytelling.
- **Run 3** produced a balanced response while the higher Frequency Penalty minimized repeated words and encouraged more varied vocabulary.

Overall, the model remained coherent across all runs while varying the creativity, diversity, and lexical richness based on the selected hyperparameters.

---

# Comparison with Batchmates

Although the same prompt was used, different batchmates obtained different responses because Large Language Models generate probabilistic outputs.

Some responses emphasized scientific exploration, while others focused more on storytelling, emotions, or adventure. Differences were observed in vocabulary, character names, writing style, and narrative flow, while the overall topic remained consistent.

---

# Key Learning Outcomes

- Understood the effect of Temperature on response creativity.
- Learned how Top-p controls token selection during text generation.
- Observed how Frequency Penalty reduces repetition in generated text.
- Gained practical experience in calling an LLM using the Groq API and Python.
- Learned how hyperparameter tuning affects response quality.

---

# Conclusion

The experiment successfully demonstrated the impact of Temperature, Top-p, and Frequency Penalty on Large Language Model outputs.

- Lower Temperature and Top-p values generated deterministic and focused responses.
- Higher values produced more creative, expressive, and diverse outputs.
- Applying Frequency Penalty reduced repetition while maintaining coherence.

Therefore, selecting suitable hyperparameter values depends on the application. Lower values are preferred for factual and deterministic tasks, whereas higher values are better suited for creative writing and brainstorming.
